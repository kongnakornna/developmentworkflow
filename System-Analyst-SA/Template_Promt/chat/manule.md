# คู่มือการใช้งาน AI Prompt Template Pack

ชุดนี้ประกอบด้วย 2 ส่วนหลัก  
1. **Master System Prompt** – สำหรับใส่ใน AI (GPTs / Claude Project / Gemini Gem)  
2. **CSV / Markdown** – เก็บ Prompt Template 24 โมดูล (00–23) ใช้เป็น Knowledge หรือเปิดใน Excel เพื่อดู/แก้ไข

ด้านล่างคือวิธีใช้งานตั้งแต่เริ่มต้นจนได้ผลลัพธ์

---

## 1. ตั้งค่า AI Assistant (GPTs / Claude / Gemini)

### 1.1 GPTs (ChatGPT)
1. ไปที่ **Explore GPTs** → **Create**
2. แท็บ **Configure**
3. ช่อง **Instructions** วางข้อความนี้

```text
คุณคือ Multi-Module AI Prompt Assistant
หน้าที่ของคุณคือสร้างเนื้อหาตามโมดูล 00-23 ที่แนบมาใน Knowledge

เมื่อผู้ใช้ระบุชื่อโมดูลหรือรหัส เช่น 04, 09, 12, 23
ให้โหลด Prompt Template จาก CSV แล้วปฏิบัติตามอย่างเคร่งครัด
ถ้าไม่ระบุ ให้ถามผู้ใช้เพื่อเลือกโมดูล

หลักการร่วม:
- เน้นหลักการสำคัญ
- ย่อคำ อธิบายสั้น จำง่าย
- มีตัวอย่างประกอบ
- ใช้ KPI / SMART / RCA / PSR / Workflow เมื่อเกี่ยวข้อง
- ใช้ภาษาเดียวกับผู้ใช้
- แสดงผลเป็น Markdown ที่อ่านง่าย
- ห้ามสมมติข้อมูลที่ไม่มี ให้ถามเพิ่มเมื่อจำเป็น
- จบด้วยสรุป 3-5 บรรทัด
```

4. ช่อง **Knowledge** → อัปโหลดไฟล์ `ai_prompt_modules.csv` (หรือไฟล์ .md ก็ได้)
5. ตั้ง **Conversation starters** เช่น

```text
ใช้โมดูล 04 สร้างบทหัวข้อเรื่อง AI สำหรับผู้เริ่มต้น
ใช้โมดูล 09 ออกแบบ Workflow การอนุมัติซื้อ
ใช้โมดูล 12 ออกแบบ Software Architecture ระบบ E-commerce
ใช้โมดูล 23 สร้างสคริปต์ TikTok เรื่อง KPI
```

6. กด **Save** → **Publish** (หรือใช้ส่วนตัว)

### 1.2 Claude Project
1. สร้าง **Project** ใหม่
2. ช่อง **Project Instructions** วาง Master System Prompt ข้างบน
3. **Knowledge** → อัปโหลด CSV หรือ .md
4. เริ่มแชตและเรียกใช้โมดูลได้เลย

### 1.3 Gemini Gem
1. ไปที่ **Gemini** → **Create Gem**
2. ช่อง **Instructions** วาง Master System Prompt
3. **Knowledge** → อัปโหลด CSV หรือ .md
4. **Save** แล้วเรียกใช้ผ่านชื่อ Gem

## 2. การใช้ CSV / TSV ใน Excel

- ไฟล์ CSV ใช้เป็น Knowledge สำหรับ AI  
- ถ้าต้องการดูหรือแก้ไขใน Excel ให้ทำตามนี้

### วิธีนำเข้า CSV
1. เปิด Excel → **Data** → **From Text/CSV**
2. เลือกไฟล์ `ai_prompt_modules.csv`
3. ตั้ง Delimiter = **Comma** , Encoding = **UTF-8**
4. กด **Load**

### วิธีใช้ TSV (Tab-Separated)
- คัดลอกบล็อก TSV ที่ให้ไป
- ไปวางที่เซลล์ `A1` ใน Excel
- Excel จะแยกคอลัมน์ให้อัตโนมัติ

### โครงสร้างคอลัมน์
| คอลัมน์ | ความหมาย |
|---|---|
| ID | รหัสโมดูล 00–23 |
| Module | ชื่อโมดูล |
| Category | หมวดหมู่ |
| Purpose | วัตถุประสงค์ |
| Prompt_Template | Prompt ต้นแบบ (มี `[ ]` ให้แทนค่า) |
| Output_Format | รูปแบบผลลัพธ์ที่แนะนำ |
| Tags | แท็กค้นหา |

## 3. วิธีเรียกใช้โมดูลกับ AI

เมื่อตั้งค่าเสร็จแล้ว การใช้งานทำได้ง่ายมาก

### 3.1 ระบุโมดูล
พิมพ์เช่น

```text
ใช้โมดูล 04
```

AI จะถามข้อมูลที่ขาด หรือถ้าคุณให้มาครบแล้วก็สร้างได้เลย

### 3.2 ใส่ข้อมูลในวงเล็บ `[ ]`
Prompt Template มีที่ว่างให้แทนค่า เช่น

```text
ใช้โมดูล 04
เรื่อง: การเขียน KPI
กลุ่มเป้าหมาย: ผู้จัดการมือใหม่
ภาษา: ไทย
```

AI จะนำไปเติมใน Template แล้วสร้างผลลัพธ์ตามโครงสร้างที่กำหนด

### 3.3 ตัวอย่างการใช้งานจริง

**ตัวอย่างที่ 1 – สร้างบทหัวข้อ**
```text
ใช้โมดูล 04
เรื่อง: Design Thinking
กลุ่มเป้าหมาย: พนักงานองค์กร
ภาษา: ไทย
```

**ตัวอย่างที่ 2 – ออกแบบ Workflow**
```text
ใช้โมดูล 09
กระบวนการ: การอนุมัติใบเสนอราคา
แผนก: จัดซื้อ
ภาษา: ไทย
```

**ตัวอย่างที่ 3 – สร้างสคริปต์ TikTok**
```text
ใช้โมดูล 23
แพลตฟอร์ม: TikTok
หัวข้อ: 3 วิธีตั้ง KPI ให้ได้ผล
ความยาว: 60 วินาที
โทน: ให้ความรู้
```

**ตัวอย่างที่ 4 – ออกแบบ Software Architecture**
```text
ใช้โมดูล 12
ระบบ: E-commerce
Requirements: รองรับผู้ใช้ 1 ล้านคน, ชำระเงินผ่านบัตรและ QR
Tech Stack: Node.js, PostgreSQL, React
```

## 4. เทคนิคใช้ให้ได้ผลลัพธ์ดี

- **ระบุให้ชัด** – ยิ่งให้บริบทมาก ผลลัพธ์ยิ่งตรง
- **ใช้หลายโมดูลร่วมกัน** – เช่น ใช้ 03 (นิยาม) → 04 (หัวข้อ) → 09 (Workflow)
- **ขอ Variations** – พิมพ์ “ขอ 3 แบบ” เพื่อให้ AI เสนอทางเลือก
- **ตรวจสอบและปรับ** – AI อาจต้องถามเพิ่มถ้าข้อมูลไม่ครบ
- **แก้ไข CSV ได้** – ถ้าต้องการเพิ่มโมดูลใหม่ ให้เพิ่มแถวใน CSV แล้วอัปโหลดใหม่

---

## 5. ตัวอย่างการใช้งานแบบผสมโมดูล

```text
ใช้โมดูล 03 และ 04
คำ/แนวคิด: OKR
กลุ่มเป้าหมาย: ทีม Start-up
ภาษา: ไทย
```

AI จะสร้างบทนิยาม (03) แล้วต่อด้วยบทหัวข้อ (04) ให้ในครั้งเดียว

---

## 6. การปรับแต่งเพิ่มเติม

- **เพิ่มโมดูลใหม่** – เพิ่มแถวใน CSV ตั้ง ID ใหม่ เช่น 24
- **แก้ Prompt Template** – แก้ในคอลัมน์ `Prompt_Template`
- **เปลี่ยน Output_Format** – ระบุเป็น “ตาราง”, “แผนภาพ”, “สคริปต์” ฯลฯ
- **อัปเดต Knowledge** – ถ้าแก้ CSV ต้องอัปโหลดใหม่ใน GPTs/Claude/Gemini

---

## 7. สรุปขั้นตอนทั้งหมด

1. สร้าง GPTs / Claude Project / Gemini Gem
2. วาง Master System Prompt ใน Instructions
3. อัปโหลด CSV หรือ .md เป็น Knowledge
4. เรียกใช้โมดูลด้วยรหัส เช่น `04`, `09`, `12`, `23`
5. ใส่ข้อมูลใน `[ ]` ตามที่ AI ถามหรือที่คุณระบุ
6. รับผลลัพธ์เป็น Markdown / ตาราง / แผนภาพ / สคริปต์
7. ปรับแต่งและนำไปใช้ได้ทันที

หากต้องการให้ผมช่วยสร้าง **ตัวอย่างการใช้จริงแบบเต็มรูปแบบ** สำหรับโมดูลใดโมดูลหนึ่ง แจ้งได้เลยครับ
