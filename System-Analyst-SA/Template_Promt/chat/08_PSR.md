อธิบาย [เรื่อง/กรณีศึกษา] ด้วยโครงสร้าง Problem-Solution-Result:
- Problem (ปัญหา): สถานการณ์ อุปสรรค ประเด็นที่ต้องแก้
- Solution (วิธีแก้): แนวทาง กระบวนการ เครื่องมือ
- Result (ผลลัพธ์): ผลที่เกิดขึ้นจริง วัดผลได้

ข้อกำหนด:
- เน้นหลักการสำคัญ
- ย่อคำ
- อธิบายสั้น จำง่าย
- มีการประยุกต์ใช้
- สรุปเป็น 3 บรรทัด
