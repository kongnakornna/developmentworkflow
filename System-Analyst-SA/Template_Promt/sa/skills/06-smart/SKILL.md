# SMART (โมดูล 06)

## Prompt Template
สร้างหรือตรวจสอบเป้าหมาย **[เป้าหมาย]** ด้วยหลัก SMART:
- S — Specific
- M — Measurable
- A — Achievable / Attainable
- R — Relevant / Realistic
- T — Time-bound

## ผลลัพธ์ที่ต้องได้
1. เป้าหมายเดิม
2. เป้าหมายที่เขียนใหม่ให้ SMART
3. KPI ที่วัดได้
4. กรอบเวลา
5. วิธีติดตามผล
