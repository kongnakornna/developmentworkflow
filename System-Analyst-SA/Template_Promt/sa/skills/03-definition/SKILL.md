# บทนิยาม (โมดูล 03)

## Prompt Template
สร้างบทนิยามของ **[คำ/แนวคิด]** โดยตอบ 3 หัวข้อ:
1. คืออะไร (What is it?)
2. วัตถุประสงค์ (Purpose)
3. เป้าหมาย (Goal)

## ข้อกำหนด
- อธิบายสั้น กระชับ
- ใช้ภาษาง่าย
- มีตัวอย่าง 1 ตัวอย่าง
- สรุปเป็นคำจำง่าย 1 ประโยค
