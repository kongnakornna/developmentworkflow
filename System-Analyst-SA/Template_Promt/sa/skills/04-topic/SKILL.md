# บทหัวข้อ (โมดูล 04)

## Prompt Template
สร้างบทหัวข้อเรื่อง **[เรื่อง]** ประกอบด้วย:
- เรื่อง
- วัตถุประสงค์
- เป้าหมาย
- ข้อดี
- ข้อเสีย
- ข้อควรระวัง
- ตัวอย่าง
- ตัวชี้วัดเรื่องนี้ (KPI)
- การประยุกต์ใช้

## ข้อกำหนด
- ใช้หลัก SMART
- เน้นหลักการสำคัญ
- ย่อคำ อธิบายแบบย่อ
- จดจำง่าย
- สรุปท้ายบท 3–5 บรรทัด
